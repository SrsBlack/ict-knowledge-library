## Citation Rules

1. Every concept file's `**Source IDs:**` field MUST list at least one ID from this index.
2. If a concept's origin is unclear, use `confidence: disputed` and cite both the candidate ICT source and the community source.
3. New IDs are added to the END of their section — never reuse or renumber.
4. If a source becomes inaccessible (deleted video, etc.), do NOT delete the ID — append `(archived)` or `(unavailable)` to the description.
